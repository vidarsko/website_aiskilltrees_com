For teachers

Make your own

A skill tree is a folder with two text files in it. Nothing needs to be installed or paid for, and the result is yours under an open licence whether or not you send it here.

This page is a sketch. The steps below are the agreed plan, but the kit, the prompt and the form are not built yet — the links are placeholders.

How it works

  1. 01

    Download the kit

    One folder with the engine, the default instructions and a placeholder subject already filled in. Open it and a working tree appears — then replace the placeholder with your own subject.

    Download the kit Not ready yet
  2. 02

    Paste the prompt into an AI

    Copy the instruction below into whichever AI chat you already use. It asks how you prefer to work, then takes you through decomposing your subject, filling in the files and checking the result.

  3. 03

    Send it in

    A form asks for the subject, the level, the country and the licence, and takes your files. Sending in is optional — the tree works on your own machine either way.

    Open the submission form Not ready yet
  4. 04

    It gets reviewed, then published

    Mechanical checks run automatically: columns present, prerequisites pointing at real nodes, no cycles. The subject-matter reading is done by hand, which takes time.

Already sent one in?

Sending a new version

Use the same form and give the slug of the tree you are updating. A tree is expected to change as a syllabus is revised or a gap turns up. Versions are kept, so what a student saw last term stays citable.
