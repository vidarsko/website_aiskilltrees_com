An open method for teachers

Skill trees for school subjects

Each tree is a graph of the skills and concepts in one subject, written by a teacher. Every node carries an instruction you can copy into an AI chat to practise that skill.

What this is

What a skill tree contains

A tree lists the skills and concepts of a subject as nodes, with an arrow from each node to the ones it builds on. The whole subject is visible at once, so a student can choose where to start and see what a given skill depends on.

The site does not call a language model. Each node composes a text instruction that you copy into whichever AI chat you already use, which means there is no account to create, no cost per student and no data processing agreement. The instructions are written to have the model ask questions rather than give answers.
