Privacy

What this site records

The skill trees record nothing about a student anywhere but in the student's own browser. Like all websites, this one handles some visitor data. This page says what.

In your browser

  • What you tick off in a tree is saved in your browser's local storage, on your device only. It is never sent anywhere. Clearing this site's data in your browser removes it.
  • The site sets no cookies and stores nothing else on your device. A language you choose is kept in the address bar, not saved.
  • When you build a tree on Make your own, your file is read in your browser. Nothing is uploaded.

Visit statistics

I count visits with GoatCounter, which uses no cookies and keeps no IP addresses. For each page view it records the page, the site you came from, your browser, operating system and screen size, and your country. Your IP address is used only to work out the country and to avoid counting one visit twice, and is not kept.

It also counts a few actions, without linking them to a person:

  • which trees are opened or downloaded
  • which kind of instruction is copied, and from which tree
  • which filters are used in the catalogue, and search words that found no tree
  • language switches, clicks on the front page's entry points, and how many trees are built on Make your own

Never recorded

  • What a student ticks off, which nodes they open, or how far they have come.
  • The text of an instruction, or anything typed into an AI chat. The site calls no language model.
  • The contents of a file you build a tree from.

Hosting

The site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security purposes, as described in GitHub's privacy statement. Fonts and scripts are served from this site itself; the only other service a page contacts is GoatCounter.

Without this site

Every tree can be downloaded as a single HTML file. It works offline and contacts no server, so a school can use the trees without visiting this site at all.
