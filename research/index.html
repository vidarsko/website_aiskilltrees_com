Software and citation

Version 0.32.0

The engine, the instructions, the language files and the starter tree are in a public GitHub repository, vidarsko/ai-skill-trees. This site publishes release v0.32.0 of it.

Each release is archived at Zenodo with its own DOI. Release 0.32.0 is 10.5281/zenodo.23240371. The DOI 10.5281/zenodo.22959546 always points to the newest release.

If you use the method or the material, please cite the release you used rather than the main branch:

Skogvoll, V. (2026). AI Skill Trees (Version 0.32.0) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23240371
